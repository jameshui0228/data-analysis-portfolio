# 허창민 데이터 분석 포트폴리오

고려대학교 산업경영공학부 허창민의 데이터 분석 포트폴리오입니다.

이 저장소는 금융/투자사 지원 시 외부에서 확인할 수 있도록 정리한 공개용 요약 저장소입니다. 일부 프로젝트의 원본 코드는 대회 데이터, API 인증 정보, private 제출 로그, 팀 협업 자료를 포함할 수 있어 별도 비공개 저장소에서 관리하며, 본 저장소에는 공개 가능한 범위의 문제 정의, 분석 접근, 사용 기술, 결과, 회고를 정리했습니다.

## 관심 분야

- 데이터 기반 의사결정
- 정량 분석 및 예측 모델링
- 통계적 사고와 머신러닝 기반 문제 해결
- 스포츠/운영/제조 데이터 분석
- 실험 로그, 모델 검증, 데이터 누수 방지, 리스크 점검

## 핵심 기술

| 구분 | 기술 |
|---|---|
| Language | Python, SQL, TypeScript |
| Data | Pandas, NumPy, Excel, Jupyter Notebook |
| ML | Scikit-learn, CatBoost, LightGBM, XGBoost |
| Validation | Holdout, GroupKFold, leakage control, calibration, drift check |
| Collaboration | GitHub, Markdown report, experiment log |
| Web/Platform | Next.js, Supabase, Vercel |

## 공개 정책

- API key, secret, raw dump, private submission, 대회 원자료는 포함하지 않습니다.
- 대회 데이터 공유 제한 또는 팀 협업 자료가 있는 프로젝트는 공개 요약만 제공합니다.
- 공개 가능한 프로젝트는 원본 저장소 링크를 함께 제공합니다.
