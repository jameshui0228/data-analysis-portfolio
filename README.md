## 일하는 방식

1. 문제와 의사결정에 필요한 정보를 먼저 정의합니다.
2. 데이터의 출처·수집 시점·사용 제한을 기록합니다.
3. 기준 모델과 비교하고, 검증 단위를 바꿔도 결론이 유지되는지 살펴봅니다.
4. 결과와 한계를 함께 정리하고, 팀이 다시 확인할 수 있는 형태로 남깁니다.

금융·투자 관련 업무에서도 자료 조사, 비교 기준 정리, 근거 확인, 보고서 작성으로 이 경험을 확장하고 싶습니다. 위 사례는 학술·개인 프로젝트이며, 실제 투자 집행이나 조합관리 실무 경력을 의미하지 않습니다.

## 공개·기여 원칙

- 공동 프로젝트의 결과와 개인 기여를 구분합니다. 커밋 기록만으로 기여율을 계산하지 않습니다.
- AI 보조 도구를 활용하며, 생성된 내용 자체보다 문제 정의·검토·검증 과정과 산출물을 보여줍니다.
- 회원 개인정보, 인증정보, 재배포 조건을 확인하지 않은 원자료와 비공개 제출 이력은 공개하지 않습니다.
- 대회 점수는 평가 방식과 기록 시점을 함께 설명하고, 미확인 최종 순위나 실무 효과는 주장하지 않습니다.
