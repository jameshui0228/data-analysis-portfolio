# 고려대학교 스포츠 데이터 분석 학술동아리 SDA

## 개요

SDA는 Korea University Sports Data Analysis의 약자로, 스포츠 데이터를 활용해 경기, 선수, 전략, 영입, 전술, 의사결정을 분석하는 고려대학교 학술동아리입니다. 창립자이자 회장으로 활동하며 커리큘럼, 세미나, 프로젝트, 발표, 내부 경진대회 운영을 총괄했습니다.

## 주요 활동

- SDA 창립 및 운영 체계 설계
- 데이터 분석 기초, 선형회귀, 로지스틱 회귀, 통계 기초, 클러스터링 등 세션 운영
- 스포츠 데이터 기반 팀 프로젝트 기획 및 관리
- 시니어 논문 세션, 정규 세션, 발표 자료 운영
- 3기 모집 홍보와 조직 확장 준비

## KU-SDA Contest 플랫폼

SDA 공식 홈페이지 및 내부 경진대회 플랫폼을 구축했습니다. 이 플랫폼은 외부 공개용 홈페이지와 동아리원 전용 Contest 기능을 함께 포함합니다.

주요 기능:

- SDA 소개, 커리큘럼, 프로젝트 Archive, 멤버, 문의 페이지
- 내부 경진대회 목록 및 상세 페이지
- CSV 제출, 자동 채점, 점수/리더보드 반영
- RMSE, MAE, Accuracy, LogLoss 채점 지원
- Supabase Auth, 회원 제한, Admin Dashboard
- 로컬 demo mode와 실제 Supabase 운영 mode 분리

## 사용 기술

Next.js, TypeScript, Tailwind CSS, Supabase, Vercel, GitHub
